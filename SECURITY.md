# Security policy

Version `0.1.x` is supported while it is in pre-release evaluation. Report vulnerabilities privately through this repository's GitHub **Security** tab using **Report a vulnerability**; do not open a public issue. Use a minimal, synthetic reproduction and do not attach private documents.

This project provides resource bounds, not a complete sandbox. Reports involving temporary files, protocol bounds, process teardown, pre-exec behavior, native decoders, or resource-limit attribution are welcome.
